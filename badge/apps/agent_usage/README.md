# Agent Usage

Agent Usage mirrors your enabled OpenUsage subscriptions over USB with circular gauges, centered reset countdowns, and stale-data warnings.

The Mac bridge supplies usage summaries; no provider credentials are copied to the badge.
The home screen uses a 3x2 matrix of remaining-allowance gauges. Claude combines outer weekly and inner session rings, leaving separate Antigravity Gemini and Claude tiles. Green is over 50% left, yellow is 21–50%, and red is 0–20%. Left/right selects an adjacent gauge; up/down moves between rows.
Select enlarges a gauge; up/down then changes metric, and Select returns to the matrix. Back returns to the matrix. Menu opens the stock launcher.
The screen stays at 80% brightness while USB-powered and sleeps after USB power is removed.
The installed startup wrapper opens this app at boot; holding Menu at boot bypasses it.
No Wi-Fi or secrets.py changes are needed.
